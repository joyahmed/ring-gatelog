# AWS CDS Agentic AI Hackathon

Entry for the AWS Communication Developer Services Agentic AI Hackathon.

**Idea:** a WhatsApp-native agentic HR assistant. Employees and managers chat on WhatsApp
(leave balance, apply for leave, approvals, payslip questions). An Amazon Bedrock AgentCore
agent answers, and its tools wrap the existing Zetta HRM services, so the HRM role guard
already decides who may do what. Demo runs on a demo tenant only.
